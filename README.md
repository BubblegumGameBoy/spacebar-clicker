# spacebar-clicker

スペースキー（タップ）でボスを倒していくクリッカー / 放置ゲーム。
HTML1ファイルで完結する静的サイトで、本番は `main` ブランチから配信される（gumgameboy.com）。

## ファイル構成

| パス | 役割 |
|------|------|
| `index.html` | ゲーム本体（HTML/CSS/JSすべて内包）。これ1つで動く。 |
| `ranking.html` | 記事下へ埋め込む、このブラウザ内のダメージランキング専用画面。 |
| `HATENA_ARTICLE.html` | はてなブログへ貼り付ける更新済みの記事HTML。 |
| `assets/` | ゲームが実際に使う素材。ボス、味方ユニット、背景、効果音、戦闘BGM。`bgm-*.mp3` と `boss-shatter.mp3` はソルジャータイピング2からの再利用。 |
| `tools/` | 生成した4コマを同じ大きさ・足元位置へ揃える処理と、ドラゴンの色違い作成。 |
| `robots.txt` | クローラ設定。 |
| `package.json` / `package-lock.json` | 開発用（playwrightでの動作確認）。配信には不要。 |
| `.gitignore` | `node_modules/` と、ルート直下の原画 `*.png` を除外（`assets/` 配下は対象外）。 |

## 動作確認（ローカル）

```sh
# どちらでもOK
open index.html                 # ブラウザで直接開く
python3 -m http.server 8000     # http://localhost:8000 で配信
```

URLに `?cheat` を付けるとクリック1発でボスを倒せるデバッグモードになる。
`?showcase` を付けると保存データを変更せず、全24ユニットを同時表示できる。
`?showcase&awaken` ではLv0 / 50 / 100 / 150の外観差も同時確認できる。
`?showcase&layout` ではユニットをドラッグして配置を調整できる。矢印キーで微調整し、「保存」でブラウザ内へ保持、「配置をコピー」でJSONを取得できる。通常プレイの配置には影響しない。
`layout-mobile.html` は390×844を基準に、小型・大型端末も切り替えられるスマホ配置エディター。内部のゲーム画面は実際のスマホ幅で動作する。
生成プロンプトと4コマ素材の仕様は [`ANIMATION_ASSETS.md`](ANIMATION_ASSETS.md) に記録している。

## 画像素材について

ゲームに使う画像は `assets/` 配下の **webp / png（軽量化済み）だけ**。
`unit_*_attack.png` と `unit_*_collect.png` は4コマの新規アニメーション素材。巨人砲兵を含む。

加工前の**原画（元素材）はリポジトリには含めない方針**（`.gitignore` で `*.png` を除外）。
以前ルート直下にあった原画一式（`*_こわい.png` などの大きいファイル、約63MB）は
未使用かつ配信を重くするだけだったため整理して削除済み。
必要になった場合は git の履歴から復元できる:

```sh
# 削除前のコミット(25e73b5)から特定ファイルを取り出す例
git checkout 25e73b5 -- "ロイガ__こわい.png"
```

## ライセンスについて

`assets/` 配下には、**有償ライセンスで購入した既存素材**と、このゲーム用に新規制作したユニットアニメーションが含まれます。
このリポジトリの閲覧者への再利用・再配布は許諾していません。
コードの参照は自由ですが、**素材ファイルのダウンロード・転用はご遠慮ください**。

## 主要なゲームシステム（index.html内）

- **ボス**: `const BOSS` 配列。全40体。最後の `クトゥルフ` を倒すと「世界平和」＝クリア。
- **ユニット**: `const UNITS` 配列。召喚→レベル強化。Lv50ごとに×50の覚醒倍率。
- **ヒーロー強化**: `const HERO` 配列（クリック強化・クリティカル・疾風の加護など）。
- **転生 (prestige)**: BOSS10到達で解放。`prestigeFactor()` の倍率が永続ゴールドに複利で乗る。
- **周回**: ラスボス撃破後に最初のボスへ進むとLOOPが上がり、全ボスHPが周回ごとに×50、獲得ゴールドが×6になる。
- **サウンド**: BOSS 1–7は穏やかな曲、8–19は通常戦、20–34はボス戦、35–40と2周目以降は最終戦曲。約1.6秒でクロスフェードし、BGM/SEは個別にオン・オフできる。
- **ランキング**: 入力した名前ごとに実ダメージを累積するローカルTOP10。名前と記録は進行セーブ・転生とは別に保存する。
