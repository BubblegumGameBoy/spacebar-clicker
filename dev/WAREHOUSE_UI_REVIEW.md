# 倉庫の受け口と在庫UIの分離（2026-10-26）

## 変更

- 倉庫の在庫panelを盤面から `deckMain` の先頭へ移した。PCは盤面右のカタログ上、スマホは盤面のすぐ下。家と搬送経路にDOMの表示・当たり判定が重ならない。
- 素材の実アイコン、大きな在庫数、短い素材名、工房への入口を表示。地面上の資材数は小さな一行とし、長い状況説明はscreen reader用statusへ残した。
- 資材を持った時だけ家の受取範囲を表示し、家に近づくと明るくなる。長い指示文は家へ入る向きの二重矢印に置換。受入範囲と納品判定は同じ家の位置を使用。
- 旧panelの下に隠れた資材数を数える処理と、カメラに合わせたpanel座標計算を削除。

## 準備済み機能試験

`tools/qa_warehouse_dock.cjs`。3言語それぞれのLANGも確認し、PC 1280×900とCDPタッチ390×844の計6構成で合格。CDPは実機ではない。

- dockとfieldの矩形の重なりなし。
- 木材・石材・食料の3列で横はみ出しなし。
- 旧panelの位置だった家の下の丸太を、実際のpointer/touch入力でつかめる。
- 家の受取範囲に持っていくとdelivery-readyになり、放すと1個だけ入庫、地面の個数0。全構成でpageerror 0。
- PC英語とスマホ英語のスクリーンショットを目視確認。家と受取範囲が見え、在庫dockは搬送経路から分離されている。
- 関連Nodeテスト `campaign-camp`, `ground-tools`, `m4-logistics` の3ファイル合格。

試験では資材と食料解放を準備している。新規セーブから稼いだ実プレイとは区別する。画像は `/tmp/qa-warehouse-dock/`、永続結果は `WAREHOUSE_UI_CHECKS.json`。
