# 鉄鉱石と手持ち磁石

2026-10-28。試遊版 `20261028-iron-magnet-r1`。日本語のみ。元ゲームは変更しない。

## 遊びの追加

平らな1600×900の既存マップと全9波を維持し、東の鉱脈を研究で見つける。鉄は採集力12で1個、相対重量4.5（木材1、石材2.5）。鉱脈は2か所・各120個で、採り尽くすと65秒後に120個へ再生する。近くへ手動配置した採掘師も採れるが、石材の2倍の採集時間がかかる。既存の採掘道具強化も有効。

手持ち磁石は長押しで鉄鉱石だけを引き寄せる。カーソルを動かして運び、倉庫へ入れるか、既存のコンベア・集積口・積み込み機へ渡せる。普通の木材・石材・食料は吸わない。箒と磁石は同時に装備せず、建設を始めると道具をしまう。道具の製作・強化は保存するが装備中のモードは保存しない。

| 研究・製作 | 費用 | 前提・効果 |
| --- | --- | --- |
| 鉄鉱採掘 | 木16・石20 | 採掘師レシピ、採集2。東に鉱脈2か所を一度だけ追加 |
| 磁石レシピ | 木12・石8 | 鉄鉱採掘、箒レシピ |
| 磁石の製作 | 木10・石6 | レシピとは別の一度きりの製作費 |
| 強力な磁石 | 木24・鉄8 | 磁石レシピ。半径85→125、力と最高速度も増加 |
| 鉄製の搬送機構 | 石30・鉄12 | コンベア、鉄鉱採掘、搬送2。実際の搬送速度を35%上げる |

統合ツリーは能力24＋レシピ14＋設備強化11＝49ノード。両強化で鉄20個を使う。搬送車輪の25%強化とは乗算し、搬送スキルの速度にも乗る。研究費の一部だけを消費することや、重複購入による二重支払いはしない。

## 実装と保存

`materials-core.js` が採集に必要な仕事量・重さ・磁性・対応する働き手を保持する。供給データ、採集、描画、資材表示、納品、運搬中の荷、研究費、実績カウンターと旧セーブ移行まで鉄に対応した。新素材は重量定義だけ増やして完成とは扱わず、これらの経路も接続する。

磁石は資材に速度を与え、既存の摩擦・柵・資源の障害物判定と納品処理を使う。長押し中の小さな力が静止速度判定で毎回消される不具合も修正した。持ち上げ中・空中・搬送中・機械内部の資材は吸わない。倉庫へ磁石で動かした鉄を直接納品しても、風や自動化の実績には数えない。コンベアへ渡った後は既存の自動搬送になる。手動道具の納品区分は再読込でも保持する。

既存ノードの座標・残量、配置済み設備・部隊・資材を保持し、`camp.oreVersion` で鉱脈の重複追加を防ぐ。既存セーブへ鉄の在庫を配布しない。転生時も拠点・研究・資材を保持する従来の処理に従う。

## 確認と限界

Node329件成功。日本語のPCマウス／CDPタッチで、研究と製作の別払い、実際の採掘と納品、採掘師の東側配置と鉄の自動採集、磁石の選別・倉庫納品・コンベア受け渡し、鉄の強化費、実搬送速度の1.35倍、再読込、画面はみ出しとJS例外を確認した。従来の箒・地図移動・4穴予告・準備待ち・積み込み機・敗北後の操作も日本語2入力で回帰確認。

以前に通常の資材でクリアした28人の拠点から、資材の追加なしで研究・磁石製作・鉄20個の採掘納品・両強化と再読込まで約163秒かけて確認した。鉄20個はすべて通常の採集・運搬で獲得し、両強化で使い切った。28人の編成も保持した。新規からの全9波再プレイとは区別する。確認結果は `IRON_MAGNET_CHECKS.json` に保存し、生のセーブとプレイヤーIDは公開しない。

CDPタッチは実機テストではない。新素材を含む新規全編の経済・高脅威・長時間の搬送詰まりまで調整済みとは扱わない。追加ステージ・硬い岩・鉄を要求する戦闘ユニットは未実装。次は東側の鉱脈と倉庫をつなぐ複数道具の実プレイを優先する。
