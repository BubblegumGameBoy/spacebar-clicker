## 再開・保存

編集用 `2/` と追加test/toolsはgit管理外。`dev/sequel-source.tar.gz` と `dev/sequel-source-wip.tar.gz` に同一内容を保存する。既存チェックアウトを使い、依頼なしに別worktreeを作らない。展開前に2/test/toolsを確認し、既存ソースを上書きしない。

```sh
# 編集ソースのない新規チェックアウトのみ
tar -xzf dev/sequel-source.tar.gz
node --test --test-isolation=none test/*.test.cjs
python3 tools/build_playtest.py .
python3 -m http.server 4427 --bind 127.0.0.1
# GAME_URL、QA_OUT、必要ならCHROMIUM_PATHを指定
node tools/qa_rising_roads_v13.cjs
# QA_TOUCH_ONLY=1 はCDPタッチ、QA_VISUAL_ONLY=1 は画面と移行のみ
node tools/qa_earned_opening_v13.cjs
node tools/qa_equipment_flow.cjs
```

Windowsのビルドは `python -X utf8`。別contextで検証し既存セーブを消さない。通常獲得の非公開storageStateはQA_OUTだけに置き、生セーブ・プレイヤーIDをアーカイブや公開記録へ入れない。公開は版名更新→build→検証→両アーカイブ同期→対象だけcommit→最新mainと調整→通常push。
