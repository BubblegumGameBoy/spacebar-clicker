# Mythos Slayers II — 最小引き継ぎ

更新 2026-11-19 JST。完成版 `20261119-campaign-r2`、ルール `campaign-v20`。まずこのファイルを読む。既存の編集ソースは中身を確認してから使う。

プレイヤーの目的は「黄昏の王を倒し、街道を取り戻す」。タイトルで目的を示し、拠点の上部で解放地域数と次の行動を伝える。最初は木と石を納めて弓兵を雇い、攻略地図から出陣する。地図は現在の地域を優先し、過去の領地と全体図を折りたたむ。初制圧後は次の攻略先と資材採集を選べる。各地域の二つの前哨を落とすと城に挑める。最後の城を落としたら、10地域の解放と小屋から育てた拠点を結末で振り返る。結末はクリア後に再表示できる。

攻略地図で10地域30陣地から行き先を選び、経路を表示してから別の平地戦場へ移る。手動配置済みの部隊が左から前後衛に分かれて進軍し、守備隊を破ったあと城門の耐久を削る。10体以上の守備隊は三群で出る。既存スプライトの弓兵・剣士には足運び、バリスタには車輪の動きを加えた。拠点の採集と搬送は遠征中も進む。

制圧地は再訪でき、木・石・鉄鉱石・麦のうち、攻略地図に示した資源を採れる。同じ手作業で実物を2個採集する。残量・地上の資材・集積・積荷は保存される。実物を直接または集積場を経由して荷車に積み、最大12個を拠点へ運ぶ。荷下ろしは地面に置く処理で、倉庫に届けた分が所持資材になる。現地へ派遣した生産班は訪問中に働く。拠点で使う設備は従来の作業場に配置する。鉄鉱石は従来の採掘研究が必要。

旧v18で交戦中の部隊は同じ戦闘を続け、帰還後に攻略地図へ進む。既存の拠点資源・班配置・研究・設備はそのまま扱う。旧試遊のセーブは `slot=new-game`。最初から遊ぶ完成版の入口は別スロット `slot=campaign`。実物の保管や移動に `S.territories` を使い、`S.factory` と `S.camp` は拠点のまま保持する。
