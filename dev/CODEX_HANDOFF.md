## 再開と保存

既存チェックアウトを使い、依頼なしにworktreeを作らない。編集用 `2/` と追加test/toolsはgit管理外で、`dev/sequel-source.tar.gz` と `dev/sequel-source-wip.tar.gz` の両方へ保存する。既存の編集ソースを上書きしない。新規チェックアウトなら先に存在を確認し、展開する。

```sh
tar -xzf dev/sequel-source.tar.gz
node --test --test-isolation=none test/*.test.cjs
python3 tools/build_playtest.py .
python3 -m http.server 4427 --bind 127.0.0.1
# 別セッション：GAME_URL、QA_OUT、必要ならCHROMIUM_PATHを指定
node tools/qa_east_logistics_v12.cjs
node tools/qa_equipment_flow.cjs
node tools/qa_iron_magnet.cjs
node tools/qa_campaign_recovery.cjs
```

Node22+・Python3・npm ci・Playwrightが必要。Windowsのビルドは `python -X utf8 tools/build_playtest.py .`、Chromeは `CHROMIUM_PATH` を指定する。新規確認は別contextで行い、既存セーブを消さない。通常獲得プレイは `tools/qa_earned_campaign_v12.cjs`、`QA_RESUME` は非公開の獲得済みstorageState、`QA_PHASE=combat` は戦闘続行。最後は `tools/qa_earned_finish_v12.cjs`。生セーブやプレイヤーIDはアーカイブ・公開記録に入れない。

公開はcache版名更新→build→対象検証→両アーカイブ同期→必要ファイルだけcommit→最新mainと調整→通常push。元ゲームやWorkerは触らない。
