# Mythos Slayers II 侵攻版設計

2026-11-16。版名 `20261116-invasion-r1`、ルール `outpost-invasion-v18`。設計担当Astraから実装担当Solへ。既存 `2/` を編集し、元ゲームを残して `preview/` のみ更新する。これは実装前仕様であり、数値と座標は試遊で調整してよい。以下の一巡と保存原則は省略しない。

## 遊びの中心

採集して納品する → 小屋で仲間と道具を整える → 地面または地図で敵陣を選ぶ → 明示した「この陣地へ出陣」で味方が歩く → 守備隊と戦う → 制圧した採集地に木こりや搬送設備を置く → 次の陣地に備える。

準備時間は無制限。兵の初配置でも時間経過でも自動開戦しない。作業場で実物資材を集め、運ぶ行為は遠征を強くする準備であり、割り込む襲撃への対処ではなくなる。出陣中も既存の採集と搬送は続く。小屋・地図の一時停止は従来どおり。

敵が倉庫へ歩く既存処理の向きを変えるだけでは成立しない。今回の必須要素は、攻略先の選択、実際に歩く味方、味方の体力と戦闘不能、帰還・再挑戦、制圧による採集地追加の5点。

## 陣地と攻略順

- 既存の30遭遇IDと10ボスを維持する。各地域の `3n+1` と `3n+2` が前哨陣地、`3n+3` が頭領陣地。地域名と敵種はCampaignCoreを再利用する。
- 地域内の前哨2つは、どちらから攻略してもよい。両方を制圧すると頭領が選べる。頭領制圧で次地域が開く。最初だけ1番を「おすすめ」とし、2番の強さも予告する。未解放地域を自由に飛び越すことはできない。
- `wave` は遭遇定義IDとして残す。選択ID、制圧済みID集合、連続して制圧した最大IDを別に持つ。2番だけクリアして1番未クリアなら、連続クリア値は0。`clearedBossWave` に単純な最大IDを入れて研究を先取りさせない。
- 地面には現在地域の3陣地を旗・敵の姿・短い名前で示す。未解放頭領は錠前、制圧済みは味方旗。全30個を常時重ねない。地図では10地域の進行と現在の3候補を見られる。
- 陣地を押す操作は選択だけ。小さな詳細に敵種、人数、ボス有無、有効な兵種、獲得する採集地、出陣人数を表示。出陣ボタンを別に設け、カード連打で開始しない。右の常設パネルは復活させない。
- 戦闘中の別陣地選択・編成変更は不可。待機中の配置は維持し、配置中や未配置兵がいる時は出陣を止め、理由と配置への導線を出す。

平地1600×900は維持する。配置案は地域中心を上段から蛇行して `(500,180),(740,180),(980,180),(1220,180),(1450,180),(1450,650),(1220,650),(980,650),(740,650),(500,650)` とする。各地域の前哨は中心から `(-45,-25)` と `(45,55)`、頭領は中心から `(0,135)`。右端・下端は安全範囲に収める。既存の木・岩・設備と重なる場合、描画位置と戦闘目標位置を同じ座標で近くの空き地へずらす。旗だけ地面からずらし、当たり判定が元座標に残る実装は不可。実装サイズ上この座標列が不適なら、既存の北・南・東の道沿いを利用してもよいが、前哨2つと頭領を地面で識別できること。

## 進軍・戦闘・帰還

内部状態は `idle / marching / fighting / returning`。結果は帰還完了まで保持する。既存Outpostの `phase='active'` は進軍から帰還まで維持して、戦闘中の編成ロックを再利用できる。

1. 出陣時に配置済みで編成中の戦闘員を固定し、各人の `id:index`、出陣前の配置、HP、現在座標を保存する。生産員はその場に残る。登録済みのgroup.positionsを現在の進軍座標で上書きしない。
2. 味方は配置位置から選んだ陣地へ実際に移動する。剣士が先、弓兵がその後ろ、バリスタはさらに後ろ。横の並びは既存の手動配置の相対順序を使い、同一点へ全員を重ねない。編成の役割と地面での配置に意味を残す。
3. 陣地の約140px以内へ先頭が入ったら交戦開始。進軍だけで敵の出現時計が消費されない。敵は選んだ陣地周辺に現れ、味方を追って攻撃する。倉庫や生産員は襲わず、物資箱を減らす処理は使わない。
4. 射程内なら攻撃し、いなければ攻撃可能な敵へ歩く。近接兵が射程外で停止したままにならない。飛行敵しか残っていない剣士が永久追跡しない。射手は射程の約75%で止まり、無限に後退して無傷で勝つ挙動にはしない。
5. 守備隊を全滅させれば制圧。分裂や荷車から出た子敵も含む。ボスが生きたまま時間経過で勝利することはない。勝利した瞬間から帰還を開始する。
6. 画面の「撤退」で任意帰還できる。撤退後は新規攻撃を止め、残存敵は陣地へ戻る。戦闘不能者は担架・薄い表示等で帰還隊に含め、同じ兵を購入し直す必要はない。戦闘員が全員戦闘不能なら自動で敗走する。
7. 帰還先は出陣前の配置。完了時に全員のHPを戻し、結果を短く表示し、次の陣地を選べる。帰還は画面内の移動で数秒程度。非常に遠い帰路や経路詰まりの対策として、帰還だけの短縮速度と一定時間後の安全配置復元を許す。

物理資材を軍隊の障害物にしない。木・岩と小屋は避ける。既存ArmySimのmulti敵モードは移動禁止なので、侵攻時の専用分岐を設ける。歩行の最終接近位置を射程円から決め、敵の中心へ全員が突っ込む目標設定を避ける。移動不能が続いた時には周辺の空き地を再探索する。

敗走・撤退ではその陣地の途中ダメージと撃破進捗を破棄する。資材、設備、仲間の人数、訓練、研究、すでに制圧した陣地は失わない。時間待ちの回復や必須の出陣料金は追加しない。失敗した陣地の再挑戦にも、もう片方の前哨へ変更する判断にもすぐ移れる。

**通常の帰還にExpeditionCore.returnHomeを呼ばない。** 既存処理は戦闘隊の人数を1に戻す周回用であり、この設計の帰還と意味が違う。旧周回の精算を残す場合は別操作「遠征記録を精算」とし、訓練リセットがあることを明示する。今回の主要導線に含める必要はない。

## 戦闘の初期値と判断

- 味方の初期最大HP案は弓兵72、剣士140、バリスタ100。他の戦闘員が既存セーブに存在する場合の安全な既定値は100。訓練は現行の人数増加を維持し、兵員数と混成が総耐久力を変える。HPを章ごとに倍化しない。
- 味方の攻撃力、攻撃間隔、射程、弓対空、剣とバリスタの貫通、敵の盾・装甲・分裂・群れ・回復は現行値を基本として再利用する。
- 敵の攻撃は通常1.8秒間隔。初期ダメージ案は鼠2、俊足2、鎧4、盾3、蝙蝠2、粘菌3、小粘菌1、モグラ4、祈祷1、鉄甲虫6、群れ3、鬼火3、荷車6、投石3。ボスは6〜12から試遊調整。ボスHPから攻撃力を自動倍化しない。
- 地上近接敵は最も近い生存兵を狙う。投石は射程130程度で後衛に届き、近接が追いつけば倒しやすい。飛行敵も味方を攻撃し、剣士に固定しているだけで無害にはならない。
- 祈祷優先と装甲優先の既存方針を有効にする。「前方優先」は倉庫までの距離ではなく、実際の味方からの距離で決める。戦闘中の目標決定で旧防衛の残り道程を参照しない。
- モグラの潜伏を旧道程だけで計算しない。侵攻中は6秒周期で約2秒潜るなど時間で進む周期へ読み替え、地上で攻撃する時間を必ず作る。鉄甲虫の正面は実際の移動または攻撃方向。鬼火は実際の味方接近で発見する。
- 既存の時間順出現計画は敵種と人数の素材として使う。守備隊は交戦開始時に一部、残りは小群で追加し、通常の全投入を20〜35秒程度までに収める。旧plan6の6秒間隔を大量の敵へそのまま適用し、数分間待つ戦闘にしない。
- 攻撃可能な味方が残っていない／双方無効な場合は「この編成では残敵を倒せません」と表示し撤退可能にする。開始から150秒を目安に攻略打切りの敗走を設けてもよい。これは準備中の強制タイマーではない。初戦は交戦20〜35秒、後半も60〜100秒程度が目安。

最初は配置済みの弓兵1人と木こり1人で1番の鼠3体に、手動連打なしで勝てる。2番は鼠4体と採石地の予告で増員を考えさせる。3番は剣士または弓兵増員を準備する意味を持たせる。初ボスで突然桁違いのHPを要求しない。

地域ごとの判断は、1:増員と前後衛、2:盾を貫く剣士、3:弓と剣の混成、4:分裂を処理する連射、5:対空弓、6:祈祷役優先、7:前衛で潜伏発見、8:装甲貫通、9:投石と荷車処理、10:対空・貫通・回復役優先の組合せ。詳細の攻略ヒントはこの侵攻文脈へ書き直す。

既存研究49個を維持する。工具・搬送設備は遠征強化用の資材供給を増やす。灯火の弓射程効果はそのまま。門の足止め効果は倉庫襲撃廃止で死ぬため、侵攻時は「門で備えた防具」として出陣HP+20%の実効果に読み替え、説明も一致させる。すでに支払った研究や建物を無効化しない。

## 制圧と作業場の接続

- 前哨の初制圧時にそれぞれ採集ノードを1つ追加する。最初の地域は木と石、2〜3地域も木と石、4地域以降は木/石/麦/鉄を組み合わせる。鉄を手に入れるには既存の採掘研究が必要で、未研究なら「鉄鉱脈確保・採掘研究が必要」と予告する。麦も既存の採集条件に合わせる。
- ノードは陣地近くの空き地に置く。ストック・再生・手動採集・生産員の判定は既存SupplyFactory方式を使う。報酬を即座に倉庫の数値へ加算しない。
- 初制圧の木と石は既存より近場または運びやすい位置とし、新規プレイヤーがすぐ木こり再配置や送風機を試せる。遠方の鉱脈・農地ほど搬送設備の接続が役立つ。現行4本の初期資源や東側既存資源は消さず、ロックし直さない。
- 追加ノードには固定の解放IDを保存し、再読込・再挑戦・精算で重複生成しない。物理上限240〜1200は変更しない。上限で詰まった時も資材の勝手な削除・無料納品はしない。
- 頭領制圧は次地域の解放、既存の初回金貨・研究進行が主報酬。頭領だけを周回して資材が自動入金される仕組みは加えない。
- 帰還結果に「採石地を確保　木こり・採掘師を配置して搬送をつなぐ」と出し、「採集地を見る」でカメラを移す。この一操作で戦闘と作業場を接続する。初戦の結果を閉じる前から新しい木が地面に見えること。

## 難易度

新規は通常、既存の脅威条件は保存する。脅威変更は出陣前だけで、一度出たら固定。章進行でHPだけを増やさず、既存敵種・人数・混成を利用する。

群れ増加、鉄の毛皮、夜の羽音、盾の列、祈祷、攻城は実際の守備隊編成へ反映。急襲は守備隊増援の出現間隔30%短縮。狭い陣地は既存の戦闘部隊枠3。片寄りは敵の左右配置偏り。地中からは潜伏敵追加。薄い備えは物資箱2ではなく味方最大HP80%に読み替える。すべて選択前に効果を表示する。効果が消える旧条件を黙って残さない。

## 初回導線

従来の採集→納品→木こり解放/雇用/配置→弓兵解放/雇用/配置までは残す。弓兵を置いても開戦しない。次の案内を「鼠の前哨を押す → この陣地へ出陣」にする。推奨陣地と出陣ボタンを画面内で見つけられる。出陣時だけ短く「仲間が進軍中。採集と搬送は続けられます」、戦闘中は味方HPと撤退ボタン、初勝利時は新しい採集地への導線を出す。

案内の終了条件を旧 `wave1/result` だけにせず、最初の制圧・帰還を反映する。「迎撃」「次の襲撃まで」「道を防衛」「物資箱を守る」等の現行導線は侵攻画面で残さない。採集・配置・道具の操作案内は維持する。

## 旧セーブと保存

新状態は独立した `S.invasion` を推奨する。OutpostCore.migrateは未知フィールドを落とすため、Outpost内部へ追加するだけでは保存できない。game-coreの保存/読込正規化まで確認する。

保存内容の例は `version, ruleset, selectedId, conqueredIds, unlockedSourceIds, stage, activeId, members, departureAnchors, fightElapsed, returnElapsed, outcome, settlementToken`。味方ごとのHP・位置・戦闘不能、敵の位置・HP・出現数、攻撃クールダウンは可能な範囲で継続する。再読込でHP全快や報酬二重付与を起こさない。

- 初回移行で既存クリア番号とrecordsから制圧済み陣地を復元。旧所持品・地上の実物・設備座標・研究・仲間・訓練・通貨・初回報酬記録を維持する。既存採集ノードは移動しない。
- 旧待機中と旧結果画面は時間襲撃を解除し、次の陣地選択へ移す。既に攻略した陣地の初回金貨は再支給しない。旧クリア済み分の採集地追加は解放IDで一度だけ行ってよい。
- **旧戦闘中は旧ルールの戦闘をそのまま完了させる。** 「進行中の防衛が終わると陣地攻略へ切り替わります」と一度表示。その戦闘を勝利扱いにしたり、途中の敵・資材・配置を消して新侵攻へ変換したりしない。旧戦闘終了後は新たな自動襲撃を開始しない。
- 旧30完了は完了を維持し、制圧済み地図と採集地を見られる。任意の陣地再戦は許可してよいが報酬を重複しない。
- 読込中に別の保存先へ切り替えたり、slot=new-gameをリセットしたりしない。生セーブとプレイヤーIDをrepoやアーカイブへ入れない。

## 実装分担と検証の境界

新規InvasionCoreに攻略可能陣地・進行状態・移行・ノード解放・戦闘をまとめる。Outpost.tickは侵攻時のみ旧OutpostCore.tickを迂回。ArmySimは侵攻専用の移動/HP分岐を持ち、既存damageイベント・Outpost.hitの装甲等を可能な範囲で利用。ArmyViewは味方HP・戦闘不能を表示。地図/小屋/チュートリアルは主な導線のみ差し替える。既存物理搬送と研究システムを書き直さない。

必須確認は次のとおり。

1. 新規セーブで時間を進めても兵配置後でも勝手に敵が出ない。
2. 普通に採集・納品・雇用した弓兵で初陣を選び、歩行・戦闘・帰還を経て新しい採集ノードを採る。準備済みデータの検証とは分ける。
3. 同地域の2番を先にクリアしても1番や研究条件を飛ばさず、両方の後だけ頭領へ行ける。
4. 弓だけで盾/装甲に苦戦し、剣士追加で改善する。飛行には弓が必要。祈祷優先が実際のターゲットを変える。
5. 撤退と全滅から人数・研究・物資を保って帰還し、別陣地または再挑戦を選べる。
6. 進軍中・交戦中・帰還中を保存読込し、位置・HP・報酬が壊れない。旧戦闘中と旧待機中の移行を別に確認する。
7. 制圧報酬ノードが再読込や再戦で増殖しない。追加ノードの資材を搬送ガジェットで実物として納品できる。
8. 新規初地域と後半の代表戦を実際に操作する。コアテストで30陣地を回しただけで全編の通常試遊済みとはしない。

完成条件は「自分で選んだ陣地へ兵が向かい、味方が傷つく戦闘を経て帰り、その勝利が次の採集と搬送の仕事を生む」一巡が画面上と保存上の両方で成立すること。
