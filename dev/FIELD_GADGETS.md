# 平地の拡張・巣穴予告・箒

2026-10-28 JST / `20261028-field-gadgets-r1`

## 今回の方向

ユーザーの修正を反映し、既存の平らな森林を育てる。公開対象は**1マップ・全9波**。採石場への移動、崖や段差、生成した採石場画像は今回の実装に含めない。今後の素材やガジェットは、この作業場へ増やす。

## 広さと操作

- 960×540から1600×900へ、面積約2.8倍。旧来の倉庫・木・石・設備・部隊を移動や拡大せず保持する。
- 東・南側に木2本と岩2つを追加。既存4資源に加えて8資源、農家を解放した場合は畑もある。`camp.fieldVersion` により追加は一度だけ。再読込・転生で増殖しない。
- 通常の初期表示は元の作業範囲を見やすい倍率。「全体」で広域へ縮小、＋／−とCtrl＋ホイールで拡縮。小地図を押すとその場所へ移動する。
- 空き地を220ms長押ししてドラッグするとカメラが動く。資源・資材・仲間・設備の操作と区別し、部隊の配置・設備設置中は地図移動の長押しを始めない。スマートフォンは地面への素早いスワイプによるブラウザスクロールへ切り替えず、長押し移動を使う。
- カメラの説明や余白は資材タップを遮らない。モバイルの説明は地面の外へ出す。主人公の移動・HPは追加しない。

## 4つの巣穴

北・南の巣穴（x925）と東の北穴・南穴（x1450）を最初から配置。経路は平面上の上下2本を延長する。

- 第1～3波は近い穴、第4～6波は各道の3体ごとに遠い穴、第7～9波は各道で近い穴と遠い穴を交互に使う。総出現数・敵HP・味方の攻撃値は従来の通常編成を維持。
- 穴に次の出現数と秒数、準備待ち・出現済み・次は出現なしを表示。折りたたみの「巣穴ごとの予告」には敵の種類も表示する。数は実際の出現予定から計算し、分裂後の子は親の出現数へ加えない。
- 出現まで20秒以下で警告色。秒数は襲撃開始と穴ごとの出現遅延から算出し、倉庫への到着時刻や架空の総戦闘力とは扱わない。
- 第3・6波の準備待ち、敗北後の停止、明示的な準備完了を維持。全9波クリア後は、再戦を始めるまで全穴を静かな表示にする。
- 新規ラウンドはplan 4。遠い穴の移動時間を確保するため、制限は第1～3波50秒、第4～6波85秒、第7～9波100秒。脅威条件やカスタム波の明示的な時間指定はその指定に従う。
- 保存済みのplan 1/2/3の戦闘は元の穴・時間で再開し、次のラウンドから新版を使う。敵と分裂した子に出現元を保存し、再読込で東の敵を旧入口へ飛ばさない。

## 箒と重さ

統合ツリーは既存43ノードにレシピと強化を加えて**45ノード（能力24・レシピ13・設備強化8）**。

| 項目 | 費用と効果 |
| --- | --- |
| 箒のレシピ | 木材6・石材2。送風機のレシピが前提。製作カードが増える |
| 箒の製作 | 木材6・石材2を別に消費。一度製作すると繰り返し使える |
| 幅広の箒 | 木材28・石材16。箒のレシピと採集手段hand1が前提。幅60→88、押す力＋55% |

「箒で掃く」を選び、地面をドラッグする。丸太の相対重量1、石2.5、食料0.6。重い物は加速と掃く速さの上限が低い。単なる座標移動ではなく速度を与え、既存の地面物理で摩擦・木や岩・柵・家・設備との衝突と搬送先への受け渡しを処理する。

伐採前の木、岩の資源ノード、仲間、設備は固定。空中・手持ち・搬送中・集積口内の物を掃かない。箒で在庫や資材を作らない。倉庫に入った実物だけ一度納品され、箒による手作業を送風機や自動化の実績へ計上しない。途中で送風機や集積口へ渡った物は従来の自動搬送として扱う。

製作済み箒と強化は拠点に保存され、転生でも残る。使用中という操作状態は保存せず、再読込では手作業へ戻す。建設や仲間の配置を始めると箒をしまう。

`GadgetCore.MATERIALS` に物理的な重さをまとめた。鉄鉱石・新しい石材・それらの採掘カードや設備はまだ追加していない。新素材には採集・表示・納品・レシピ費用の対応も必要で、重量定義だけで追加済みとは扱わない。
