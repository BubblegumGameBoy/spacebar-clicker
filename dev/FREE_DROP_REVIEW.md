# 手で運んだ資材を地面へ置く（2026-10-26）

ユーザーの「送風機の前に資材を置きたい」に対応。以前は家・ベルト・受け土台以外で放すと元の場所へ戻っていた。

## 実装

`2/outpost-camp.js` の `groundRelease` と `endDrag` のみを変更。盤面内の地面で正常に放せば、つかんだ資材を手元へ置き、地面の物理に戻す。最初の資材はつかんだ時の指との相対位置を保ち、残りは12px間隔・上下5pxの小さな列にする。各資材は元のオブジェクト・countのままで、束にはしない。

置いた資材のベルト・受け土台・集積口・飛行中・元の採集位置のタグを解除し、`physical=true` とする。在庫は増やさず、倉庫への納品と同じ経路を使わない。位置は即保存する。ベルト・受け土台への投入と家への納品は従来経路を維持。

pointer captureでUIや盤面外に出た場合は地面扱いにしない。Escape、pointercancel、lostpointercapture、blur、オーバーレイ中も元位置を維持。地面は物理エンジンと同じ上下左右の範囲を使う。

`tools/qa_free_ground_drop.cjs` を使用。資材や送風機を準備した機能試験であり、新規セーブから稼いだ進行ではない。
