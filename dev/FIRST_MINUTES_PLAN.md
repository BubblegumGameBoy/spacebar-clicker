# 最初の4分の設計（2026-10-26、オーナー指摘を反映）

目的：長文を読まず、資材が実際に動くこと・自動化の意味・防衛の必要を順番に体験する。

- 開始：木と家、在庫だけ。盤面の指が木をたたく場所を示す。丸太が出たらその実物から家へ運ぶ指へ切り替わる。
- 木材6：初めて斧を持った木こりのカードが現れる。雇う→自分で木のそばへ置く→仲間の丸太を運ぶ。
- 木こりの丸太を納品し木材4：送風機が現れる。資材を風の前へ手で置くこともできる。自動で家へ入る成功を見せる。
- 自動納品後（遅くとも初襲撃90秒前）：弓兵が現れ、石材を採って運ぶ手→雇用→射程の届く配置へ。風や部隊を自動建設しない。
- 初回襲撃はゲーム内240秒の時間トリガー。仲間を置くことや『襲撃開始』クリックを条件にしない。最終60秒は実際の敵の絵が入口で予告される。メニュー中・非表示中は既存の停止処理に従う。保存で残り時間を保つ。
- 通常は90秒、後半120秒の既存周期で続く。章3・6後も準備時計を自動で再開。敗北後の再挑戦/帰還は選択を残す。既存の開始ボタンは任意の『早送り』。
- 最初の襲撃前は木こり・送風機・弓兵を段階表示。1回防衛すると採掘師・剣士・柵、章1を越えると残りの一覧。解放したカードは購入で在庫が減っても消さない。
- 強化の全一覧は最初から見せない。風の納品後に在庫10で入口を出す。導入中の購入画面は1枚の効果と費用に絞る。
- 倉庫の在庫UIは盤面外。家そのものが受け口。手持ち中だけ受け取り範囲を示す。

検証は実プレイ（新規・可視操作のみ）と準備済み時計試験を区別する。CDPは実機ではない。音は未試聴。新規実プレイで木こりの実納品、保存して再開、地面への放下と送風機の作用、3言語の在庫UIを確認する。
