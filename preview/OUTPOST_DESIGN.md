# 現行の遊びと画面（2026-10-23）

## 遊びの流れ

木を連打して丸太を落とす → 倉庫へ10個ドラッグ納品 → 木材10個で持ち運びを1個から2個へ強化 → 木こりを雇い、自分で配置 → 木こりの丸太を手で納品 → 自分でコンベアを敷設 → 実際の自動納品を確認 → 所持木材30個で4個持てるかごへ → 弓兵2人を配置 → 準備完了で初回90秒の襲撃時計が始まる。

長押しの自動採集はしない。1回のタップ・Space押下ごとに資材が落ちる。採集スキルは1打の産出を増やすが、各資材は個別の実物のまま。最初の準備が終わるまで敵は襲わない。

資材は同じ出力地点に重なり、地面の物だけ軽く浮遊する。束の数字へ統合しない。上限は合計12個、資材を使った作業スキルで24・48・80・120・180・240個へ拡張。上限で採集を止め、納品で再開する。コンベア上の実物も上限へ含むので、搬送速度や経路の改善に意味がある。

## 画面と配置

- モード選択のメニューはない。購入欄の仲間・設備カードから対象を直接選ぶ。
- 押下中は配置の予告、指を離すと確定。配置後は通常の採集・運搬に自動で戻る。
- 配置中だけ、対象名・短い案内・キャンセルを表示。未配置の雇用取消は明示して返金する。
- 既にいる仲間は、そのキャラクターを選んで再配置できる。中断された未配置人数は購入欄から再開できる。
- PCは右の細い購入欄、記事のiframeやスマホなど幅980px以下では下の横スクロールカード列。
- 小屋の在庫は小さな表示にまとめ、工房も小型ウィンドウにする。工房を開いている間はゲームと準備時計を停止する。

## 自動化と防衛

細いコンベアと広い受け土台（4方向）を手動で組む。触れた物だけを運び、小屋到着で初めて在庫へ加算する。途中で切れた経路では物が止まる。木こりの位置によって落下先が変わり、予告と実際の落下に同じ計算を使う。

襲撃は全9回。初回は導入完了時にプレイヤーが準備完了を押してから90秒。以降は序盤・再挑戦90秒、後半120秒の準備後に自動開始する。既に襲撃を始めた保存には初回練習を強制しない。主人公HPはない。敵が小屋へ着くと物資箱を失い、箱がなくなれば同じ襲撃へ再挑戦する。敗北しても資材・仲間・設備は残る。

工具・門・灯火は必須条件ではなく任意の準備。灯火は弓兵の実射程を90から110へ広げる。クリア後に交易機能が始まるとは表示しない。

## 作業スキルツリー

持ち運び・採集・搬送・置き場の4枝×6段階、24ノード。つながった中央の図で全体を見て、未解放のノードも効果と費用を確認できる。購入は選択詳細から行う。持ち運びの序盤費用は木材10→30→60個。運ぶ上限は1→2→4→6→8→12→16、1打の産出は1→2→3→4→5→6→8、搬送速度は最大3倍。資材の自動回収や経路の自動建設はしない。

取得可能なスキル数を入口に表示し、穏やかな発光で知らせる。減動設定では発光アニメーションを止める。導入の納品累計10・30・60は保存し、資材を使っても減らない。所持数と累計はラベルを分け、スキルの費用は常に倉庫の所持資材から支払う。

全9襲撃の旧導入での実測は約24分。新しい導入・強化を含む現行版は改めてプレイ時間を確認する。24ノードを理由に数時間の内容があるとは扱わない。

## 検証の範囲

### 手仕事をレールに置き換える

手動回収は地面の木石をつかみ、小屋へドラッグして離す操作へ変更する。
素材の束、運ぶ途中、小屋の在庫は別の状態として見せる。小屋以外で離した時、
操作を中断した時には資材を失わない。レールはこの運ぶ仕事を自動で担う。
タップだけで自動納品する旧操作は、ドラッグとの対比を弱めるので主操作から外す。

仲間は木石で、レール・荷車は市の報酬Gで購入する。採集と防衛を同じ成長に
結びつけ、採集役の増員・道具・戦闘役のどこへ投資するかを作る。倍率を指数的に
重ねず、人数の増加、作業間隔、配送容量が実際の仕事量に反映される。

### 終わりと検証の扱い

最後の成功では実際の拠点を描き、人数・自動回収・手仕事と仲間の採集実績を
振り返る。勝利後に勝手に襲撃を再開しない。拠点を眺めるか、明示的に最終防衛を
再挑戦する。再読み込みで初回報酬は重複しない。旧3回版の保存も続きから遊べる。

AIによる実入力の新規通しプレイは9回目まで成功。最終防衛は弓20・剣8で敗れ、
正規資材で弓24へ増員して荷箱2で成功した。記録には高速な入力と座標の読取を
使うため、一般ユーザーや子供の標準所要時間とは扱わない。別の小学生視点レビューも
実在児童のテストではない。『操作できた』と『人が満足した』を同じ合格にはしない。

## 2026-10-23 — 作業場・物理コンベアの改訂

## 2026-10-23 — 配置操作の統一
採集・運搬／仲間の配置／コンベア／受け土台を、同じ操作パネルで切り替える。現在のモード名、選択状態、共通の「配置を終える」を常に表示。各種配置は押下中に予告を見て、指を離して確定する。複数の配置モードを同時に有効にしない。
配置終了は雇用取消と分離し、未配置の仲間と返金履歴を保持。仲間も配置後にモードを維持し、明示的に終了する。未配置人数を別表示する。資材を拾うには採集・運搬へ戻る。既存の設置用コスト・回転・取り消し操作を共通パネル内へ移動し、重複する旧ショートカットを非表示にした。
メニューやモード切替時に押下中の予告を破棄。古い指離しでは設置しない。メニューのEscapeはメニューだけを閉じる。襲撃開始では途中の配置を終え、未配置の仲間は残す。
検証：正規の採集→9個納品→木こり雇用→配置待ちを残してモード往復→配置→手動敷設→21秒無操作で搬送を確認。スマホの実タッチでも採集・納品後に全4モードの切替を確認。別AIレビューでもPC1280・スマホ390で表示とモードの一致、メニューのEscapeを確認。結合テスト5項目（メニュー、押下中切替、兵士の指離し確定、blur中断、襲撃中断）は資材を用意しタイマーを短縮した試験用状態で行い、通常進行の通し試遊とは分けた。
