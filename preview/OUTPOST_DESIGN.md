# 拠点を作り、荷を守り、回収を任せる

2026-10-20。作者本人の追加フィードバックと、革命家・編成・復帰・初見の
独立レビューを受けた構造変更。既存ボスのHPを時間内に削るだけのWave化はしない。

## 中心にする遊び

木と石を手で採る → 落ちた束を家へ運び入れる → 木石で仲間を増やす →
次の襲撃の道を見て兵を置く → 荷箱を守る → 市の報酬で回収レールを作る。
以前は自分で拾っていた木が家へ届き、自分は石や次の襲撃に集中できる。

敵は家の食料を狙う小型の略奪者。友軍は指定位置から動かず、敵だけが道を進む。
主人公HPはなく、敵が家へ到達するとその回の報酬箱を1つ持ち去る。
箱が0なら再挑戦。所持資材・仲間・設備を失わず、木石だけで兵を追加して備え直せる。

## 最初に作る縦切り

- 上下2本の道、小型ネズミ、弓兵と足止め役、荷箱3つ、襲撃3回。
- 上の道 → 下の道 → 両方の道と予告し、射程と置く場所を判断材料にする。
- 襲撃には短い制限時間がある。準備中は急かさず、開始は自分で選ぶ。
- 資材は倉庫へ到着して初めて加算する。手動回収にも短い運搬と入庫の反応を付ける。
- 市のGはまず設備へ使う。兵を買う主通貨は木石で、採集と戦闘を切り離さない。
- 最初の成功報酬で木側1か所の回収レールを買える。次は石側へ延伸する。
- ボス40体・魂・強化倍率は最初の10分の進行から外す。旧試遊は別に残す。

## 初期の調整値（実プレイで検証して変える）

| 用途 | 値 |
| --- | --- |
| 木こり | 木6＋既存人数×4、1個／5秒 |
| 石ほり | 木8＋人数×4・石4＋人数×2、1個／6秒 |
| 弓兵 | 木12＋人数×6・石6＋人数×3、G不要 |
| 最初の木側レール | 32G、一つの採集場所から家へ自動搬送 |
| 石側への延伸 | 40G |
| 襲撃1の初回成功 | 基礎12G＋初回20G＋残箱×2G |
| 最後まで遊んだ敗北 | 8G、途中撤退・読み直しでは支給しない |

単価・生産量を指数で同時に増やさず、人数が増える効果を主役にする。
報酬は敵1体ごとやオフライン時間から無制限に生成しない。
全ての敵が倒れるか家まで到達してから精算する。空の画面で制限時間を待たせない。

## 修正を引き継ぐ点

Spaceはフォーカス中のボタン操作を優先。言語と測定のフォーカスを保つ。
配置候補に後から資材が落ちない。待ち人数は取り消して返却できる。
ネズミ素材のコマ境界からのはみ出しを修正し、被弾反応は敵だけに短く出す。
カーソルは木＝斧、石＝ピッケル、敵＝武器、資材＝拾う手へ変える。
倉庫の在庫表示と入庫演出を家へ結び付け、左上の大きなパネルを外す。

これは設計案だけで完了とせず、この一周が実際に遊べる版を作って再レビューする。

## 固定版1からの構造修正

通常プレイで上下1人ずつの弓兵だけで三回とも箱3つが残った。
配置の学習は成立した一方、人数を増やす動機が弱いと独立レビューで指摘された。
そこで三回目はHPや総数を増やす代わりに、上下3匹ずつを同時に
0/1.5/3秒の群れで出す。追加の兵、剣の足止め、手で助ける判断を検証する。
初回・二回目は道の役割を覚えるための難度を保つ。


## 9回の防衛を遊び切る構成（2026-10-22）

最初の3回だけで評価を終えず、3章・9回の有限な一周へ広げる。

| 章 | 防衛 | 新しく考えること | 拠点の変化 |
| --- | --- | --- | --- |
| はじまり | 1〜3 | 上道、下道、同時の群れ。人数と配置を覚える | 木こり・石ほり、最初の回収レール |
| しごとば | 4〜6 | 速い敵、盾持ち、剣の足止め | 採集道具I・II、大きな荷車、4か所の自動回収 |
| まちへのみち | 7〜9 | 上下の増援、密集した群れ、最後の隊長 | 門、灯り、守り抜いた拠点の記念画面 |

準備は無制限。開始は自分で選ぶ。時間上限は順に50・60・70秒だが、全敵の
決着がつけばその時点で終わる。4回目には採集道具のどちらか、7回目には門、
9回目には灯りが必要。次に必要な設備から工房を直接開ける。
盾の軽減は剣が無視し、剣は相手を短時間遅くする。最後は隊長を倒し、荷箱も
1つ以上残して成功。主人公HP、味方の自律移動、画面全体の揺れは入れない。

### 手仕事をレールに置き換える

手動回収は地面の木石をつかみ、小屋へドラッグして離す操作へ変更する。
素材の束、運ぶ途中、小屋の在庫は別の状態として見せる。小屋以外で離した時、
操作を中断した時には資材を失わない。レールはこの運ぶ仕事を自動で担う。
タップだけで自動納品する旧操作は、ドラッグとの対比を弱めるので主操作から外す。

仲間は木石で、レール・荷車は市の報酬Gで購入する。採集と防衛を同じ成長に
結びつけ、採集役の増員・道具・戦闘役のどこへ投資するかを作る。倍率を指数的に
重ねず、人数の増加、作業間隔、配送容量が実際の仕事量に反映される。

### 終わりと検証の扱い

最後の成功では実際の拠点を描き、人数・自動回収・手仕事と仲間の採集実績を
振り返る。勝利後に勝手に襲撃を再開しない。拠点を眺めるか、明示的に最終防衛を
再挑戦する。再読み込みで初回報酬は重複しない。旧3回版の保存も続きから遊べる。

AIによる実入力の新規通しプレイは9回目まで成功。最終防衛は弓20・剣8で敗れ、
正規資材で弓24へ増員して荷箱2で成功した。記録には高速な入力と座標の読取を
使うため、一般ユーザーや子供の標準所要時間とは扱わない。別の小学生視点レビューも
実在児童のテストではない。『操作できた』と『人が満足した』を同じ合格にはしない。


## 手仕事・強化・自作の運搬を結ぶ修正（2026-10-22）

この節を旧自動接続の仕様より優先する。

- 石ほりは専用のピッケル4動作へ差し替え。盾と斧の戦闘兵の流用をやめる。
- 手で採る操作は長押しでも可能。初期は毎秒1個、速い連打だけが得になる形を外す。
- 資材は1個ずつ地面に描き、初期は1個ずつドラッグして家へ納める。32個の束にはしない。
- 資材スキルは持つ・採る・運ぶの3枝6段階。費用・前提・現在能力を確認して選ぶ。
- 容量を上げると、つかんだまま別の資材をなぞって追加できる。容量以上には持てない。
- レール購入は完成した接続を渡すボタンではない。採集点を選び、地面に経由点を
  一つずつ置いて家へつなぎ、長さに応じた費用を見て確定する。戻す・やめる・外すも可能。
- 荷車は自分で置いた線を走り、到着して初めて在庫になる。同じ採集点の運送中は
  次便を出さず、長い経路ほど輸送量が下がる。荷車速度の強化も実際の運搬へ反映する。

現在の4採集点・9防衛は短い試作であり、この修正で数時間遊べるゲームが完成したとは
扱わない。加工・目的地選択・橋への納品・縦の土地拡張はEXPANSION_DESIGN.mdの
未実装計画へ分け、待ち時間やWave数だけを増やして長さを作らない。


## 2026-10-23 — 作業場・物理コンベアの改訂

現行仕様は、手動採集→同じ見た目の資材をドラッグで小屋へ納品→木こりを好きな位置に配置→落下地点を見てコンベアを組む、という流れ。木こりの位置によって落下地点が変わる。仮置きの曲線と実際の落下先は同じ計算を使う。固定された資源出口へ落とす中間案は廃止。

コンベアは出口側から引き伸ばして敷く。帯状コンベアと96×64の受け土台（4方向）を隣接させて組む。地面の実物が接触した時だけ動き、途切れた先では止まる。小屋へ到達して初めて在庫が増える。資材をつかんでも別のアイコンに変えない。

襲撃は準備時間の終了で自動開始。初回150秒、序盤・再挑戦90秒、後半120秒。メニューでは停止、建設中は進行する。手動開始を前提とした過去の記述は旧仕様。

検証：126件の自動テスト、11件の音響技術チェック。新規の正規採集からPCで木こり・落下予告・敷設・無操作での納品を確認。スマホでも9個を個別に手運びして木こりを雇い、左右の予告と配置後の落下を確認。実時間150秒後の初回襲撃も確認。受け土台と隣接コンベアへの手動投入動画は正規資材で撮影。受け土台の各方向・保存の結合テストには準備済み状態を使用。

限界：現行仕様で全9襲撃を通した再検証、数時間の経済設計、音色の実聴評価は未完了。以前の最終戦動画は旧版の記録であり現行版の通しクリア証明ではない。
